### 候補契約と維持した許容差

元の要素別判定 `abs(actual-reference) <= a + r*abs(reference)` を残した上で、候補では特徴を消費されるベクトルごとに比較した。`bboxInput` / `classInput` は query ごとの128成分、`residualCorners` と head の raw `corners` は query・辺ごとの33成分を1群とした。異なる query・辺をまとめない。

reference ベクトル `v`、差 `d=actual-reference` に対し、`a=2e-4`、`r=1e-4` で次の**両方**を要求した。

1. `L2(d) <= L2(a*1 + r*abs(v))`
2. `Linf(d) <= a + r*Linf(v)`

これは許容領域の形を変える工学的な候補で、元の要素別判定より緩い場合がある。IEEE FP32 の誤差上界の証明ではない。元の要素別 FAIL を、この候補の結果で書き換えない。

| 比較対象 | 絶対許容差 a | 相対許容差 r |
| --- | ---: | ---: |
| 元モデルの最終 logits | `2e-4` | `1e-4` |
| 元モデルの最終 boxes / references | `2e-5` | `1e-4` |
| 学習中の logits / boxes・各損失 | `2e-4` | `2e-4` |
| 全8テンソルの勾配 | `2e-4` | `2e-3` |
| SGD 更新後の重み | `5e-6` | `2e-5` |

encoder TopK の300 index と順序、各 Hungarian matching は完全一致を要求した。固定 LQE の bit 単位の不変性、非ゼロ bbox / class 勾配、boxes の変化、損失低下に加え、各画像で全8テンソルの格納値が実際に変わることも条件だった。

各入力の target は、空、1個、2個の3種類。1個は label `[0]` / normalized cxcywh box `[.5,.5,.4,.3]`、2個は labels `[0,15]` / boxes `[[.2,.3,.25,.35],[.7,.65,.2,.3]]`。各 case は同じ pretrained 初期重みから始める。2個の case では FP32 SGD、学習率 `1e-4` で2 step を実行する。native / ORT CPU / browser はそれぞれ自身の prefix 特徴を使う。同じ native 特徴を全環境へ渡す比較だけで代替しない。

### 学習計算の部分一致と FP32 丸め

各 runtime 自身の prefix を使う18 target case /12 SGD step では、matching・4種類の損失・全8テンソルの全勾配・更新後の値が既定の比較を通ったと記録されている。勾配の最大絶対差は CPU 約 `6.68e-5`、browser 約 `1.39e-4`、更新後の重みの最大差は両方約 `2.98e-8`。固定 LQE は不変で、各画像の multiple-target case で非ゼロ bbox / class 勾配、boxes の変化、損失低下を観測した。

一方、`phase-17` の class bias 80成分は、元 PyTorch でも2 step とも同じ FP32 値へ丸められた。勾配は非ゼロだが、最大の `lr*gradient` 約 `1.64e-7` が、その成分の半 ULP 約 `2.38e-7` より小さかった。全8テンソルの実変化を要求した条件は FAIL のまま保持した。学習率を後から変更したり、対象テンソルを除外したりして合格にしなかった。

これらは既存80クラスの最終ヘッドに限る結果であり、完全 detector backprop、少量データへの過適合、独自クラスの実用精度を示さない。

### 原因を絞る手掛かり

元の phase 0 /37 /91 では、同一 native 入力を使う decoder self-attention / deformable attention / LayerNorm の計54出力比較が通ったと記録されている。ただし、独立した部品 export の比較であり、全グラフの全演算が同等だという証明ではない。

矩形の追加診断では encoder LayerNorm 出力は許容差内、encoder box MLP 出力は許容差外となった。同じ ORT 入力を元の encoder box MLP へ渡した比較は最大絶対差約 `9.54e-7` で通った。上流から入る小さな差が MLP で増幅することと整合するが、最初に差を生じる backbone / encoder の演算は特定できていない。具体的なモデル修正は完成していない。

# 設計判断の記録

重要な方針を、結論だけでなく理由とともに残します。新しい作業では [PRODUCT](../PRODUCT.md)、[STATUS](../STATUS.md) と関連する記録を確認してください。

| 番号 | 状態 | 内容 |
| --- | --- | --- |
| [0001](0001-onnx-first.md) | 方針は採用。モデル・エンジンは検証待ち | ブラウザ学習と初期版 ONNX 出力、事前学習済み検出器を中心にする |

## 記録する内容

- 判断日と状態: 提案、採用、置き換え済みなど。
- 背景となる要件。
- 検討した選択肢と、それぞれの利点・負担。
- 選んだ方針と理由。
- まだ確認できていない点。
- 実装や検証への影響、関連する PR・証拠。

後の判断で変更するときは新しい連番を追加し、以前の記録から後継へリンクします。過去の判断を、最初から違う内容だったように書き換えません。軽微な誤記やリンク修正は既存文書を修正します。
